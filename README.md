# Spark TANK MVP

A lightweight, mobile-first market intelligence terminal prototype.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Deploy

This repo is GitHub Pages-ready. The included workflow publishes `main` automatically once GitHub Pages is configured to use **GitHub Actions**. GitHub documents this workflow model and the repository-site URL pattern in its Pages documentation.

## Product direction

- Phone-first PWA/terminal
- Dense professional market UI
- Modular data-provider adapters
- Demo data now; live market/news/macro providers later
- Open source during the early/beta phase

## Important

The numbers in the MVP are demo data and are not investment advice.
